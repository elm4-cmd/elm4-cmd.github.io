Privacy Policy for Fablefront

Last updated: 1 November 2026. Applies to the Fablefront game and this app-specific support website.

Responsible developer and contact

Fablefront is provided by Emil Lindström. For privacy questions, support or a request concerning a support message you have sent, contact support.elmcr4@gmail.com.

Data used by the game

The game stores progress, unlocked maps, best results, win counts, language choice and sound preference in the app's local storage on your device. These records run the game and remember your choices. There is no in-game account, login or developer-operated cloud save service.

The current game does not include advertising, in-app purchases or analytics services. It does not send these local save files to the developer or provide an in-game sharing function. It does not request access to your location, contacts, camera, microphone or advertising identifier. Gameplay works offline.

Fablefront uses Godot and standard AndroidX/Kotlin runtime libraries. The reviewed game does not integrate advertising, analytics, purchase or diagnostics-upload SDKs, and it has no app-controlled network communication.

Local debug test builds can write game-state and performance diagnostics to Android's system log. There is no in-game diagnostics-upload service. The closed-testing release is checked separately for disabled debug instrumentation. Android and Google Play can provide their own platform diagnostics according to their settings and policies.

Optional support email and test feedback

If you choose to email support.elmcr4@gmail.com, the developer receives your email address, message and any attachments you choose to include. These are personal data when they identify or relate to you. They are used to answer your request, investigate reported problems and follow up on the issue, not for advertising or mailing lists.

Support uses Gmail, provided by Google, to handle email. Google's handling is described in its privacy policy. Sending email is optional and is outside the game's automatic operation; merely playing does not send a support message. Do not include passwords, private notifications or unrelated device logs.

Retention, deletion and security

Local saves remain until app data is removed or replaced using your device's app-management functions. Clearing app data removes progress and preferences. Normal app updates are designed to preserve them. Android and the device manufacturer can handle backup, restore or device-to-device migration according to system behavior and settings; this is separate from a cloud service run by the game.

Support correspondence is kept only as long as needed to answer and follow up on the request or to meet applicable legal obligations. You can ask for access, correction or deletion of your support information by emailing the contact above. Information that must be retained for a legal obligation may be kept for that purpose. There is no server-side game account to delete.

The developer uses the device's app storage and the support provider's access controls. No claim is made that email is anonymous or that the app adds its own encryption to local save files. Avoid sending information that is unnecessary for the issue.

This website and service providers

This static site does not add analytics, advertising scripts, external fonts, forms or browser-storage tracking. It is hosted using GitHub Pages. GitHub records visitors' IP addresses for security when a Pages site is visited; see GitHub Pages data collection and the GitHub Privacy Statement. Visiting the site is separate from offline gameplay, and the game does not automatically send progress to it.

Google Play, Android, your email provider and the browser can handle data under their own settings and policies. This policy's statements about the game do not imply that those independent services process no personal information.

Audience and changes

The game's intended audience is people aged 16 and over. The game does not ask for a birth date or create user profiles. Intended audience is separate from any age rating assigned by a rating authority. If you believe a support message contains personal information that should be removed, contact the developer.

This policy will be updated if the game's or support website's practices change. The published policy and Google Play declaration must describe the version actually distributed.
